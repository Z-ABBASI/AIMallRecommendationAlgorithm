# AIMallRecommendationAlgorithm
Good malls can be hard to find. You may like the concept of malls and see their potential but struggle to find any which live up to it. There are a lack of mall recommendation algorithms, so this is the first. Pinterest is very good at recommending malls, and it has the unique feature of seeing other pins you interact with and recommends malls based on those, in the same homepage, in it's recommendation algorithm.

To open:
    docker compose up

To close:
    Ctrl + C
    docker compose down

To run updated code:
    docker compose up --build

This project is created and coded heavily assisted by ChatGPTEdu 5.2, with the database tables being I altered the code provided by ChatGPT.
